# Code of Conduct

## Our pledge

We want this project to be a respectful, constructive place for everyone. We
welcome participation regardless of background, identity, experience level, or
the way someone chooses to use the software.

## Expected behavior

- Be respectful, specific, and open to technical disagreement.
- Assume good intent and give actionable feedback.
- Keep discussions focused on improving the project and its users' experience.
- Protect other people's private information, credentials, and infrastructure.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing credentials, private logs, personal data, or exploit details.
- Deliberately disruptive behavior or bad-faith reports and pull requests.

## Enforcement

Maintainers may edit, remove, or reject contributions and may limit
participation when this code is not followed. To report a concern, open an
issue asking for a private follow-up and do not include sensitive details.

This code applies in repository issues, pull requests, discussions, and other
project spaces.
