# Security Policy

## Supported versions

Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** flow in the repository
Security tab. Include a minimal reproduction, affected version, and impact.

Do not publish OAuth tokens, bearer tokens, credential files, customer data, or
an exploit proof of concept in a public issue. If private reporting is not
available, open a public issue requesting a private contact channel without
including sensitive details.

We will acknowledge a valid report, investigate it, and coordinate a fix before
public disclosure.
